Remote Control

Pair a phone or tablet to change themes, text, names, and layout without touching the display computer.

How It Works

The remote controller is a web page, so there is no app to download. Pair it with the poster and you can change themes, colors, layout, text, and host names from any device, in real time.

Requirement: the poster and the remote must be on the same network. That can be venue Wi-Fi, ethernet, or a phone's cellular hotspot.

Pair a Device

  1. On the poster computer, press W or click Wireless Remote in Quick Controls.
  2. On your phone or tablet, connect using any one of these:
    • Scan the on-screen QR code.
    • Open the displayed web address and enter the pairing code.
    • Copy and share the direct link.
  3. When the status turns to connected, the pairing window closes by itself.

The pairing code is remembered, so a page refresh on the poster does not require a new pairing.

What You Can Control

  • Choose themes and colors, and adjust sliders and layout.
  • Edit poster text and labels.
  • Add and remove host names.

Tips and Troubleshooting

  • Both devices must be on the same network. Guest Wi-Fi networks sometimes isolate devices; if pairing fails, switch both to a phone hotspot.
  • Keep the poster page open on the display computer. The remote talks to that page.
  • If the connection drops, reopen the remote link, or press W on the poster for a fresh code.
